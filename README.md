# Timbre releases

Downloads and the [Sparkle](https://sparkle-project.org) update feed (`appcast.xml`) for Timbre, a sound-design sidecar for Ableton Live 12.

To install, download the latest `.dmg` from [Releases](../../releases) and drag Timbre to Applications. It updates itself after that.

Everything here is published by `scripts/release.sh`; please don't edit `appcast.xml` by hand.
